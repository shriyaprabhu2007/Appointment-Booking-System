# 🏥 Appointment Booking System

A modern web-based **Appointment Booking System** developed using **Python Flask** and **SQLite**. This application allows users to book appointments online, view all booked appointments, and manage appointment records through a simple and user-friendly interface.

## ✨ Features

- 📝 Book appointments online
- 📋 View all booked appointments
- 🗑️ Delete appointments
- 📅 Select appointment date and time
- 📱 Responsive and attractive user interface
- 💾 Store appointment details using SQLite

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- SQLite

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/shriyaprabhu2007/Appointment-Booking-System.git
```

### 2. Navigate to the Project Folder

```bash
cd Appointment-Booking-System
```

### 3. Install the Required Package

```bash
pip install flask
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open in Your Browser

```
http://127.0.0.1:5000
```
